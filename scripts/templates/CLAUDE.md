# <GAME_NAME> 翻訳方針

このファイルは `tl-translate` がバッチ翻訳の system プロンプトに読み込む。
実際の方針に合わせて書き換えること。

## 文体

- 一人称: （例: 「私」「僕」など、キャラクターごとに決める）
- 敬語: （例: 基本は敬語なし。フォーマルな場面のみ丁寧語）
- 語尾: （例: キャラクター固有の語尾があれば記載）

## 直訳構文

直訳を避ける一般的な原則（語順・構文を写さない、要らない代名詞を書かない、等）は
`tl-translate` が system プロンプトに自動で入れる。ここにはこのゲームで目立った直訳の癖を
×/○ の対で足していく。

- （例: ×「〜してほしいの？」(Do you want me to) → ○「〜しようか？」）

## 訳さずに済ませる語

英語の語を毎回律儀に訳すと翻訳調になる（she/her →「彼女」、please →「お願い」など）。
原作の訳（locked）があれば、`tl-qa` の翻訳調の測定（`scripts/translationese.py`）が
「原作が訳さずに済ませている語」と原作の手本を出すので、ここに書き写す。

- （例: she/her →「彼女」は原作 5%。主語・所有者は書かない。「彼女の髪に」→「髪に」）

## 固有名詞

- 人名・地名・アイテム名などの固有名詞は `glossary.tsv` を優先する
- 未収録の固有名詞は音訳を基本とし、`glossary.tsv` に追記していく

## その他の注意

- プレースホルダー（`{playerName}` 等）やタグ（`<color=...>` 等）は翻訳せずそのまま残す
- 改行コードはゲームの表示崩れに直結するため、原文の改行位置を尊重する
